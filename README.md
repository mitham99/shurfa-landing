# شُرفة SHURFA — منصة الفعاليات والتجارب السياحية

موقع ثابت (HTML/CSS/JS) بلا أدوات بناء — يُرفع كما هو على GitHub Pages أو أي استضافة.

## بنية الموقع
```
شُرفة (المنصة الأم)               ← index.html
├── عن شُرفة                       #about
├── الجواز الرقمي                 #passport
├── الفعاليات والتجارب            #events   (تُبنى من data.js)
├── الخدمات                        #services (تُبنى من data.js)
├── الشركاء                        #partners (تُبنى من data.js)
└── القسم الختامي / التحميل        #download

صفحات الفعاليات
└── مهرجان صحار                    ← sohar-festival.html
    (التذاكر، الباقات، الجواز الرقمي، سوار الأمان، المنظومة الرقمية للمهرجان)

صفحة الشركاء + نموذج الانضمام       ← partners.html
```

## الملفات
| الملف | الغرض |
|---|---|
| `index.html` | الصفحة الرئيسية لمنصة شُرفة |
| `sohar-festival.html` | صفحة فعالية مهرجان صحار وتجربتها الرقمية الكاملة |
| `partners.html` | صفحة الشركاء ونموذج طلب الانضمام |
| `assets/js/data.js` | **الفعاليات، الخدمات وحالتها، أنواع الشركاء، والشركاء المعتمدون** |
| `assets/js/config.js` | **روابط المتاجر، حسابات التواصل، معلومات الاتصال، استقبال طلبات الشراكة** |
| `assets/js/main.js` | التفاعلات المشتركة (القائمة، الظهور عند التمرير، الجواز، تبويبات وباقات المهرجان) |
| `assets/js/home.js` | عرض الفعاليات والخدمات والشركاء في الرئيسية |
| `assets/js/partners.js` | نموذج طلب الانضمام |
| `assets/css/style.css` | الهوية البصرية والمكونات المشتركة |
| `assets/css/home.css` / `event.css` / `partners.css` | تنسيقات كل نوع صفحة |

## إضافة فعالية جديدة
1. انسخ `sohar-festival.html` باسم جديد (مثل `new-event.html`) وعدّل نصوصها وخدماتها بحسب الفعالية.
2. في `assets/js/data.js` أضف عنصرًا جديدًا إلى `events` (يوجد مثال جاهز داخل الملف) مع `url: "new-event.html"`.
3. ستظهر بطاقتها تلقائيًا في قسم الفعاليات بالرئيسية، مع حالتها (متاحة / قريبًا / منتهية).

## تغيير حالة خدمة أو إضافة شريك
- **الخدمات:** في `data.js` ← `services`، غيّر `status` إلى `live` (متاح) أو `event` (ضمن الفعاليات) أو `soon` (قريبًا).
- **الشركاء:** أضف الشركاء المعتمدين فقط في `partners` مع نوعهم وشعارهم. قبل ذلك يعرض القسم مجالات الشراكة بحالة «قريبًا».

## ما الذي تضعه لاحقًا
- **روابط التحميل:** `config.js` ← `stores`.
- **الشعار:** `assets/img/logo.svg` و `assets/img/logo-light.svg`.
- **صورة السوار:** `assets/img/wristband.png`.
- **صور الفعاليات:** حقل `image` في `data.js` (صور رسمية فقط).
- **استقبال طلبات الشراكة:** `config.js` ← `partners.formEndpoint` أو `partners.email`.

## ملاحظات صيانة
- الترويسة والتذييل وأيقونات SVG مكررة في الصفحات الثلاث؛ أي تعديل عليها يُطبَّق في كل صفحة.
- عند تعديل ملفات CSS/JS ارفع رقم الإصدار `?v=` في روابطها داخل الصفحات حتى تظهر التعديلات فورًا للزوار.
- الإنجليزية لاحقًا: التنسيقات تستخدم الخصائص المنطقية (`inline-start/end`)، فيكفي إنشاء نسخ بـ `lang="en" dir="ltr"`.

## الهوية البصرية (الشعار والأيقونات من «دليل هوية شُرفة»)
- **المرجع:** مجلد `Brand/` — لا يُرفع إلى GitHub (يحتوي دليل الهوية الكامل).
- **ملف التطبيق:** `assets/css/brand.css` — يطبّق الشعار وأيقونات الهوية فقط؛ الخط والألوان والأزرار والنقشة من `style.css`.
- **الشعار:** `assets/img/brand/` — القفل الأفقي على الكمبيوتر، والمونوغرام منفردًا على الهاتف (أقل من 768 بكسل).
  الملفات الحالية مستخرجة من دليل الهوية؛ استبدلها بملفات الشعار الأصلية عند توفرها بنفس الأسماء.
- **الأيقونات:** رموز `b-...` من حزمة «Shurfah Icon Pack V2» في البطاقات والتبويبات (24 بكسل فأكبر)؛ والأيقونات الخطية `i-...` للأحجام الصغيرة.
  اللون الأساسي للأيقونة يتبع لون النص، ولون التمييز يُضبط عبر المتغير `--ia`.

## الجواز الرقمي — كيف يعمل
- **بطاقة ولاء لكل شريك:** كل زيارة لشريك = ختم في بطاقة هذا الشريك فقط. لا توجد نقاط، ولا تُجمع الأختام بين شركاء مختلفين.
- **الشريك يحدد المكافأة:** مثال مطعم: 6 زيارات ← خصم 30% في السابعة ← الثامنة مجانًا. مثال ألعاب: 3 مرات ← الرابعة مجانًا.
- **يومياتي:** توثيق الرحلة بصور من المكان وسطر قصير عن الشعور في تلك اللحظة.
- **العرض التوضيحي:** البطاقات واللحظات في `assets/js/main.js` (`PASSPORT_CARDS` و `PASSPORT_MOMENTS`).

## صفحات الفعاليات (قالب واحد لكل المهرجانات)
- **القالب:** `assets/js/event.js` يبني صفحة أي مهرجان من بياناته في `assets/js/data.js` ← `events`.
- **صفحة كل مهرجان:** ملف خفيف برابط خاص (مثل `sohar-festival.html` و `dhahirah-festival.html`) يحدد العنوان وصورة المشاركة، ويحتوي فقط على:
  `<div id="eventRoot" class="ev-page" data-event="sohar-festival"></div>`
- **الهوية:** إطار شُرفة (الترويسة، الأزرار، التذييل) ثابت، ومشهد المهرجان (الشعار، الألوان، الصورة) من `theme` و `logo` و `image` في بياناته.
- **الخدمات:** `page.services` تحدد التبويبات الظاهرة بالترتيب: `tickets` · `packages` · `passport` · `safety`.
  إذا كانت فارغة تظهر الصفحة بحالة «قريبًا» (كمهرجان الظاهرة حاليًا).

### إضافة مهرجان جديد
1. ضع صورته وشعاره (PNG بخلفية شفافة) في `assets/img/events/`.
2. أضف عنصرًا في `events` داخل `data.js` (انسخ عنصر مهرجان الظاهرة وعدّل: `id`، الاسم، الموقع، الحالة، `logo`، `image`، `theme`، `page`).
3. انسخ `dhahirah-festival.html` باسم جديد، وغيّر فيه: `data-event` والعنوان `<title>` والوصف وصورة `og:image` واسم المهرجان في الشريط السفلي.
4. اجعل `url` في بياناته يشير إلى الملف الجديد — تظهر بطاقته في الرئيسية تلقائيًا.

> صورة المشاركة `og:image` مكتوبة برابط كامل على GitHub Pages؛ غيّرها إذا انتقل الموقع إلى نطاق آخر.
