# صفحة هبوط شُرفة SHURFA

صفحة ثابتة (HTML/CSS/JS) بلا أدوات بناء — تُرفع كما هي على أي استضافة.

## الملفات
| الملف | الغرض |
|---|---|
| `index.html` | محتوى الصفحة ونصوصها (الأقسام مُعلَّمة بتعليقات) |
| `assets/css/style.css` | الهوية البصرية (الألوان في `:root` أعلى الملف) والتصميم المتجاوب |
| `assets/js/config.js` | **روابط المتاجر، حسابات التواصل، معلومات الاتصال** |
| `assets/js/main.js` | التفاعلات + محتوى الباقات (`PACKAGE_ITEMS`, `PRESETS`) وأختام الجواز (`PASSPORT_STAMPS`) |

## ما الذي تضعه لاحقًا
- **روابط التحميل:** في `config.js` ← `stores.appStore` و `stores.googlePlay`. عند إضافتها تختفي شارة «قريبًا» ويُولَّد رمز QR تلقائيًا.
- **الشعار:** `assets/img/logo.svg` (للخلفية الفاتحة) و `assets/img/logo-light.svg` (للتذييل الداكن). حتى ذلك الحين يظهر شعار مؤقت.
- **صورة السوار:** `assets/img/wristband.png` (يُفضّل بخلفية شفافة). حتى ذلك الحين يظهر رسم توضيحي.
- **صور الباقات (اختياري):** أضف `image: "assets/img/pkg-food.jpg"` لأي عنصر في `PACKAGE_ITEMS`.
- **التواصل:** في `config.js` ← `social` و `contact`؛ يظهر كل عنصر فقط عند تعبئته.

## المعاينة محليًا
```bash
python3 -m http.server 5173
```
ثم افتح http://localhost:5173

## الإنجليزية لاحقًا
التنسيقات تستخدم الخصائص المنطقية (`inline-start/end`)، لذا يكفي نسخ `index.html` إلى `en/index.html` مع `lang="en" dir="ltr"` وترجمة النصوص.

## هيكل الصفحة
1. **الواجهة الرئيسية (Hero)**
2. **اكتشف شُرفة:** الخدمات الأربع في تبويبات (`#explore`). تتنقل تلقائيًا كل 8 ثوانٍ حتى يتفاعل الزائر — غيّر المدة من `DURATION` في `setupTabs` داخل `main.js`. يمكن فتح تبويب محدد من أي رابط بإضافة `data-tab="packages"` مثلًا.
3. **ابدأ الآن:** التحميل (`#download`)
4. **التذييل**

## صفحة الشركاء (`partners.html`)
- يُفتح من زر «انضم كشريك» في الترويسة (وفي قائمة الهاتف والتذييل).
- الأقسام: واجهة الشركاء ← من يمكنه الانضمام ← ما الذي نقدمه ← آلية الانضمام ← نموذج الطلب (`#apply`).
- التنسيق في `assets/css/partners.css`، ومنطق النموذج في `assets/js/partners.js`.
- **استقبال الطلبات:** ضع رابط الاستقبال في `config.js` ← `partners.formEndpoint` (يُرسل JSON بطريقة POST)،
  أو بريدًا في `partners.email` كبديل. إذا تُركا فارغين يظهر للزائر أن الاستقبال سيتفعّل قريبًا (لا يُعرض نجاح وهمي).
- الترويسة والتذييل وأيقونات SVG مكررة في الصفحتين — أي تعديل عليها يُطبَّق في `index.html` و `partners.html` معًا.
