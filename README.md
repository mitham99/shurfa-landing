# شُرفة SHURFA — صفحة الهبوط

موقع ثابت (HTML/CSS/JS) بدون أدوات بناء. هذا المجلد هو **ما يُرفع إلى المستودع وينشر**.

## التشغيل محليًا
```bash
python3 -m http.server 5173
```
ثم افتح http://localhost:5173

## أين أعدّل؟
| أريد أن… | الملف |
|---|---|
| أضيف روابط المتاجر أو التواصل أو استقبال طلبات الشراكة | `assets/js/config.js` |
| أضيف فعالية أو أغيّر حالة خدمة أو أضيف شريكًا | `assets/js/data.js` |
| أفهم البنية كاملة | `../02_docs/05_website-technical-guide.md` |

## قواعد سريعة
- عند تعديل CSS/JS ارفع رقم `?v=` في روابطها داخل الصفحات.
- لا أكواد داخل HTML (`onclick`، `onerror`، `<script>` داخلي)؛ سياسة الأمان (CSP) تمنعها.
- لا تضع أي مفتاح سري أو كلمة مرور في هذا المجلد؛ كل ما فيه عام.
